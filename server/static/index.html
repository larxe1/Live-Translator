One-Time Microsoft Edge Setup (3 Easy Steps)

1
Open Edge Extensions Open a new tab in Microsoft Edge, paste edge://extensions in the address bar, and press Enter.
2
Turn On Developer Mode Toggle the Developer mode switch ON (on the left sidebar or top-right of the Extensions page).
3
Load the Extension Folder Click Load unpacked, paste this folder path, and select the folder. It stays installed permanently!
